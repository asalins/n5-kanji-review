# data-sources/

Raw external data used ONLY by `scripts/dataset` at build time. Never imported by `src/`.
Raw files are git-ignored (only this README and `.gitkeep` are tracked). See `/DATA_SOURCES.md` for
sources, licences and attribution.

- `kanjidic2/kanjidic2.xml` : official KANJIDIC2 file (decompressed)
- `jmdict/` : reserved; JMdict is not used in Phase 3
